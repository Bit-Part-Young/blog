# 绘图软件 Origin 使用

- 学生版申请与安装：[Origin 2024 安装](https://mp.weixin.qq.com/s/GsJg4G5MjAJAh8DlZSRAkQ)
- 只有 Windows 版本，无 Linux 和 macOS 版本：[Help Online - Quick Help - FAQ-1099 Can I install Origin on M-X (M1, M2, etc.) MacBook?](https://www.originlab.com/doc/Quick-Help/Install-Origin-on-Mac-M1)
- 免费版、学生版只能打开 12 个窗口，超过此数目的窗口会被锁住
- **最实用：F1 快捷键唤起开始菜单，搜索你想要的关键词（建议英文搜索）**
- **实用：F11 快捷键（或 “帮助 - Learning Center”）查看绘图示例、分析示例和学习资源**
- 界面设置成中文：帮助 - 更改语言
- 菜单栏
	- 上方：数据、绘图、设置、帮助等
	- 左侧：项目管理器、消息日志、提示日志
	- 右侧：添加 App 及其他 Apps、连接器
	- 下方：可对 Graph 进行旋转
- 批量导入数据文件：数据 - 连接多个文件
- 关闭快速使用模式：当数据点较多时，会在图层中生成 “快速使用模式” 水印；图 - 快速模式，选择关闭
- **设置绘图模板**：右键 - 保存格式为主题（建议只勾选 “所有样式” 和 “尺寸”）
- **使用绘图模板**：设置 - 主题管理器（F7 快捷键；点击主题，右键可选择删除主题及编辑）
- **批量绘图**：安装 **Batch Plotting** App，绘制好一张 Graph 后，点击 Batch Plotting，选择 “Plot with new sheet”，勾选你想批量绘图的 Book（可取消勾选 “Rescale Axes”）
- **批量导出图片**：点击项目管理器 - 选中一个 Graph - 右键，选择 “导出图形（高级）” - “选择图形”，选择 “当前文件夹中的所有图”
- 修改坐标轴标签：右键 - 属性
- 去除图片过多空白：右键，调整页面到图层
