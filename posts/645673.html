交大常用网址汇总

|总字数:2.4k|阅读时长:7分钟|浏览量:

交大常用网址汇总

  • 整理：By 小小角色、海心
  • 整理时间：2021.11.29，不定期更新维护
  • 思源笔记地址：交大常用网址汇总 - CodiMD
  • 该内容在博客、推送、思源笔记上同步发布

前言

整理了一下自己用到过（看到过）的校内网址，并按自己的使用频率进行了一定的排序，应该对新入学的交大研究生师弟师妹们有些用处。

欢迎在博客或推送评论区处评论添加，一起补充。

生活类

jaccount 登录验证码自动识别油猴插件

jAccount 验证码在线 ResNet 高速高精度毫秒级识别

  • 学校的很多网站都需 jaccount 登录，输验证码；该插件可解决输验证码的烦恼，自动识别；需提前安装油猴（tampermonkey）

我的数字交大

我的数字交大

  • 各种服务事项大多都可以在里面完成，集成度很高，有网页版也有 app
  • 交大 V 卡、多码合一、出入校申请、体育馆预约、图书馆预约、电子地图、个人收入等，自己探索

交大柠檬

  • 非 PC 网页，微信小程序，交大学生闲置物品交易平台（类似二手交易群）；也可以发个人生活动态（思源湖底）
  • 微信搜索 “交大柠檬” 即可
  • 另一个校内买二手书的微信小程序：知十
  • 校内买二手书的线下门店：朝花夕拾（南洋南路，棒球场、涵洞附近）

交大生存手册

README - SurviveSJTUManual

  • 新入学的交大本科生看比较适用，研究生也可以看看

水源社区

水源社区

  • 交大人的社区论坛，有一些还不错的帖子（个人常逛）

交大财务计划处

上海交通大学财务计划处

  • 查询自己的工资明细，比 “交我办” 的详细一些

交大学生事务中心

上海交通大学学生事务中心

  • 奖助学金发放公告的地方
  • 可查看勤工助学、助教工资情况 #22.04.05 添加

葡萄 - 校园 PT

葡萄 :: 登录

北洋园PT :: 登录 - Powered by NexusPHP

  • 热门影视资源下载，不过不是太活跃，资源做种情况不是很好，热门资源还行
  • IPV4 和 IPV6 均可登录，即校内校外均可登录
  • 建议注册北洋园 PT（天津大学 PT 站），该 PT 站较活跃，用学校邮箱注册即可

交大云盘

交大云盘

  • 网页打开，可以找到 PC 端和手机端软件下载口
  • 1T 空间，上传/下载速度快，可达 15MB/s，只能校内使用；校外使用需打开交大 VPN（有专门的软件）
  • 可以使用同步功能，将常用的某个文件夹同步到云盘中，以防丢失，同步到多台电脑

交大第二课堂

第二课堂

  • 部分活动报名的地方，如献血报名，志愿活动报名等，名额需抢，挺激烈的

上海交通大学网络信息中心

上海交通大学网络信息中心

  • 校园网、交大云盘、正版软件、jCloud 云服务、IPV6、邮箱、高性能计算服务；集成度较高

软件授权中心

上海交通大学软件授权中心 # 21.12.24 添加

  • 一些工程软件（Endnote、matlab、solidworks、origin 等）

正版软件授权中心

软件列表 - 上海交通大学正版软件授权中心 # 23.07.03 添加

  • 上面的补充（如北太天元、WPS、福昕 PDF、VirtualBox 等）

交大邮箱

交大邮箱

SJTU-NIMO! 上海交通大学学生网络信息管理部

  • 含有宿舍安装连接网络教程

交大网络测速

  • 可以测校园网和寝室里的网络速度和延迟情况

  • 校标放置规范

上海交通大学在线教学平台 Canvas

Canvas

密院 Canvas # 密院 canvas 网址

密西根学院生存指南 # 交大密西根学院生存指南 22.06.30 添加

  • 自己所选课程的课程老师会在上面发布课程相关教学资料，有教学录像回放

  • 有辅助的教学资料下载程序

GitHub - skyzh/canvas_grab: 🌐 One-click script to synchronize files from Canvas LMS.

  • 有教学录像倍速播放油猴插件
    • 最新的插件版本可以退出画中画，可将录屏大小调整至和录像视频一样大小，可随意拖动位置
    • 倍速播放选择更多 21.12.01 添加

上海交通大学 Canvas 平台课程视频播放器至尊版焕然一新插件

  • 有辅助的教学录像下载程序

GitHub - prcwcy/sjtu-canvas-video-download: SJTU Canvas 视频 (批量) 下载器

交大图书馆
