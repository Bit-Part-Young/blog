  • 使用 lpad 命令时，出现如下报错：
    • 参考：AttributeError: “safe_load()” has been removed · Issue #531 · materialsproject/fireworks · GitHub
    • fireworks 的最新 Release 版本为 2021 年的，很老；GitHub 中的 fireworks 源码有对该问题进行解决，下载源码之后 python setup.py install 重新安装该包；或使 ruamel.yaml<0.18.0
  • 使用 Python 代码生成 workflow，并添加到 lpad 中，出现 cannot encode object: True, of type: <class 'numpy.bool'> 报错：
    • 参考：bson.errors.InvalidDocument: cannot encode object: True, of type: <class ‘numpy.bool_‘> · Issue #522 · materialsproject/fireworks · GitHub
    • 有可能是 NumPy 版本的原因，使 numpy<=1.26.4
  • my_qadapter.yaml 中的 walltime 参数会转换成秒的整数，不符合 Slurm 脚本规范
    • 可注释该参数
